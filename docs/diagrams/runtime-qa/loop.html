The model / tool cycle

A complete reply either proposes tools or ends the inner stage.

The model receives a goal, history and granted schemas. Tool calls pass the bounds and gateway, then their results feed another model request. A reply without tools checks the recorded plan and verifies published artifacts before success. Incomplete plans fail. Limits, waits and loss of ownership may stop dispatch; no automatic verification repair is shown.
