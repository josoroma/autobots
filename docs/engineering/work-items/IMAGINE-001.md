# IMAGINE-001 — Autobots visual concepts

## Plan

Create six coherent desktop interface images in `docs/imagine` from the selected Option B specifications. Cover the goal composer, active run, exact-action approval, completed result/evidence, OpenRouter setup and reusable workflow. Package the images in a local gallery with prompt provenance and concise design notes.

Scope: concept artwork and its local viewing documentation. Product implementation and backlog status changes are outside this work item.

## Implemented

Generated all six screens using the built-in image-generation tool and the home image as the common visual reference. Copied final PNGs into the requested directory while retaining original generated files. Revised the approval comparison to remove invented vendor names. Added an offline static gallery, design notes, saved prompts and an artifact manifest.

The proposed interface uses warm neutrals, forest green, a persistent sidebar, visible work plans and observable activity. It presents local storage and OpenRouter inference distinctly.

## Review

The coordinator inspected all six final PNGs, including the corrected approval screen. An independent reviewer examined source alignment before generation and reviewed the final package. Final findings and verification are recorded in the [evidence summary](../evidence/IMAGINE-001/summary.md).

## Verification and runbook

The [gallery runbook](../../imagine/README.md#local-viewing-runbook) opens the self-contained HTML gallery or any PNG. Artifact verification checks PNG integrity and dimensions, screen/prompt coverage, local links and content hashes. Evidence distinguishes static artifact checks from visual review; these checks do not establish application behavior, accessibility conformance or product acceptance.

No application dependencies or services are required to view the delivered files. Application files and specification statuses were not changed.
